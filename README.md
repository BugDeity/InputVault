# InputVault

自动记录电脑上**复制过**的文字、文件、图片和**打过**的字，随时搜索、一键还原回去。当前是 v0.3 原型。

## 功能

- **剪贴板历史**：复制的文字自动保存；重复内容只存一条，并记录用过几次
- **复制的文件**（v0.3）：登记文件位置，以后一键还原到剪贴板，直接粘贴到文件夹、微信、邮件，不用再跑回原来的地方复制
  - 文件被移动或改名：用 NTFS 文件编号自动找到新位置
  - 文件被删除：20 MB 以下的文件复制时自动存了副本，用副本还原（文件名不变）
  - 文件复制后被修改过：还原时让你选用现在的版本还是复制时的版本
  - 当初是剪切的，还原时也按复制处理，不会再把文件移走
  - 密码库、私钥、证书类文件不自动备份
- **复制的图片 / 截图**（v0.3）：保存图片本身，还原时可以作为图片粘贴，也可以作为 PNG 文件粘贴，或另存为
- **拖拽**（v0.3）：从面板里把记录直接拖到文件夹、聊天窗口、文档里
- **打字记录**（v0.2）：直接读取输入框里的最终文字，中文输入法没问题
  - 聊天框：每次发送（输入框被清空）存一条
  - 文档：只记录这次新写的部分，不会把整篇文档重复存
  - 打了一半又删掉的草稿也会留下，方便找回
- **记录来源**：在哪个应用（微信、Edge、记事本……）、哪个窗口
- **自动识别类型**：链接、邮箱、电话、路径、JSON、代码、数字
- **全文搜索**：中文可以直接搜（SQLite FTS5 trigram），还能加过滤条件
- **快捷面板**：`Ctrl+Shift+V` 唤起，回车直接粘贴到原来的窗口；`Tab` 只看当前应用的记录
- **隐私保护**：
  - 密码框一律不读
  - 遵守密码管理器设置的“不要记录剪贴板”标记
  - 默认跳过 KeePass、1Password、Bitwarden、远程桌面等应用；终端和资源管理器不记录打字
  - 身份证号、银行卡号、API Key、私钥不记录
  - 浏览器地址栏不记录（否则等于记下浏览历史）
  - 托盘菜单可以随时暂停；面板里右键某条记录可以“不再记录这个应用”

## 哪些软件能记录打字

打字记录靠 Windows 的 UI Automation，要目标软件支持才行：

| 软件 | 情况 |
|---|---|
| Edge / Chrome 网页里的输入框、文本框、富文本编辑器 | ✅ 实测可以 |
| 记事本、Qt 写的软件、Windows 原生输入框 | ✅ 实测可以 |
| Claude 桌面版 | ✅ 实测可以 |
| 微信 PC 版（4.x） | ✅ 实测可以 |
| IntelliJ IDEA、WebStorm 等 Java 软件 | ❌ 读不到，只能记录剪贴板 |

**探测工具**：想知道某个软件能不能记录，运行下面的命令，然后在 20 秒内到那个软件的输入框里点一下、打几个字。它只显示控件类型和文字长度，不显示内容。

```bash
.venv\Scripts\python.exe tools\uia_probe.py --focus
```

## 运行

第一次运行前先装依赖：

```bash
python -m venv .venv
```

```bash
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

之后双击 `start.bat` 启动（无控制台窗口），程序常驻在右下角托盘。想看报错时用：

```bash
.venv\Scripts\python.exe -m inputvault
```

开机自启：按 `Win+R` 输入 `shell:startup`，把 `start.bat` 的快捷方式放进去。

从 v0.1 升级：直接启动新版即可，数据库会自动升级，旧记录都标为“复制”。

## 主窗口

- **左侧**：分类（全部 / 收藏 / 文本 / 链接 / 文件 / 图片，有记录时还会出现路径 / 代码 / 邮箱 / 电话 / 数字）和应用来源（所有出现过的程序，按记录数排序），两组可以叠加，比如“图片”+“微信”；内容多时左侧栏可以滚动
- **中间**：记录列表，按天分组，可以按时间或使用次数排序；每行右边的“⋯”是更多操作
- **筛选中提示条**：分类、应用、排序、搜索词只要有一项不是默认状态，列表上方就固定显示当前条件，点 × 单独取消，点“恢复默认”一键还原
- **右侧**：详情，三个按钮“复制内容”“引用到输入框”和按类型变化的第三个（打开来源应用 / 打开所在位置 / 另存为），下面是原始信息
- **复制不关窗口**：“复制内容”（Shift+Enter）只放进剪贴板，窗口留着、底部提示“已复制”，可以接着复制下一条；只有“引用到输入框”（Enter）会收起窗口去粘贴
- **两种打开方式**：快捷键唤起时像弹窗，回车把内容粘贴回唤起前的窗口，切到别的程序时自动收起；点托盘图标打开时是普通窗口，可以最小化、最大化
- 拖顶部空白处移动窗口，拖窗口边缘改变大小，双击顶部空白处最大化；跟随系统深色 / 浅色

## 快捷键

| 按键 | 作用 |
|---|---|
| `Ctrl+Shift+V` | 打开 / 关闭面板 |
| `↑` `↓` `PgUp` `PgDn` | 选择 |
| `Enter` / 双击 | 粘贴到原窗口 |
| `Shift+Enter` | 只复制，不粘贴 |
| `Tab` | 切换“全部应用 / 只看当前应用” |
| `Ctrl+O` | 打开文件所在位置 |
| `Ctrl+P` | 收藏 / 取消收藏（收藏的不会被自动清理，在左侧“收藏”里集中查看） |
| `Ctrl+D` | 删除这条 |
| 拖拽 | 把记录拖到别的窗口 |
| 右键 | 粘贴、复制、以文件形式粘贴、另存为、打开所在位置、收藏、删除、不再记录这个应用 |
| `Esc` | 关闭 |

搜索框里可以加过滤：`报价 app:微信`、`type:链接`、`type:文件`、`type:图片`、`ext:zip`、`src:打字`、`src:复制`。

文件记录在右侧预览里显示每个文件现在的状态：

| 状态 | 含义 |
|---|---|
| ✅ 原位置可用 | 直接还原 |
| 🔄 已找到新位置 | 被移动或改名了，已自动找到 |
| ⚠️ 复制之后被修改过 | 还原时让你选版本（有副本时） |
| 💾 原文件已不在，使用副本 | 用复制时存下的副本还原 |
| 🗑️ 在回收站里，没有副本 | 先从回收站还原原文件 |
| ❌ 找不到，也没有副本 | 只能看信息 |

## 数据和配置

数据在 `%LOCALAPPDATA%\InputVault\`（托盘菜单“打开数据目录”）：

- `inputvault.db`：所有记录（SQLite，**未加密**）
- `files\`：文件副本、图片、缩略图（按内容哈希命名，同样的内容只存一份）
- `restore\`：用副本还原时临时放置的文件（恢复原文件名用），一天后自动清理
- `config.json`：配置。常用项在托盘菜单“设置…”里改，立即生效
- `inputvault.log`：日志，未处理的异常也记在这里

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `hotkey` | `ctrl+shift+v` | 唤起热键，比如 `alt+v`、`ctrl+alt+space`、`win+shift+f2` |
| `capture_typing` | `true` | 是否记录打字 |
| `blacklist_apps` | 密码管理器等 | 这些程序里复制和输入的内容都不记录（填 exe 文件名） |
| `typing_blacklist_apps` | 终端、资源管理器 | 这些程序只记录复制，不记录打字 |
| `typing_min_chars` | `2` | 少于这么多字的输入不记录 |
| `capture_files` | `true` | 是否记录复制的文件 |
| `capture_images` | `true` | 是否记录复制的图片 |
| `backup_max_mb` | `20` | 不超过这个大小的文件自动备份；图片超过这个大小不保存 |
| `blob_quota_mb` | `2048` | 副本和图片总共最多占用的空间，超出时先清理最久没用、没收藏的 |
| `skip_sensitive` | `true` | 跳过身份证、银行卡、API Key、私钥 |
| `max_chars` | `100000` | 单条最多保存的字符数 |
| `retention_days` | `0` | 超过多少天自动删除（收藏的除外），0 表示永久保留 |
| `panel_limit` | `200` | 面板最多显示多少条 |

> 注意：`Ctrl+Shift+V` 在浏览器、VS Code 里原本是“粘贴为纯文本”，被 InputVault 占用后那个功能就失效了。介意的话在设置里换一个热键。

## 项目结构

```
inputvault/
├─ app.py               入口：托盘、热键、设置、还原，把各模块串起来
├─ collector.py         剪贴板采集（文件 / 文字 / 图片）+ 来源应用识别
├─ filerefs.py          复制的文件：登记信息、判断现在在哪
├─ blobs.py             副本和图片的存放（按内容哈希去重）
├─ restore.py           还原：构造放回剪贴板 / 拖拽用的数据
├─ housekeeping.py      副本空间上限、清空
├─ media.py             图片编码、缩略图
├─ typing_collector.py  打字采集：后台线程轮询焦点输入框
├─ typing_tracker.py    打字会话：把一连串快照整理成“这次打了什么”
├─ uia.py               UI Automation 封装
├─ storage.py           SQLite 存储、去重、全文搜索、数据库升级
├─ classify.py          内容类型识别
├─ privacy.py           隐私过滤
├─ hotkey.py            全局热键
├─ win32.py             Windows API 封装（ctypes），包括 NTFS 文件编号
├─ textutil.py          时间、预览文字格式化
├─ apps.py              记住程序 exe 路径（显示程序图标、打开来源应用）
└─ ui/
   ├─ panel.py          主窗口外壳：无边框窗口、顶部搜索、三栏布局、快捷键
   ├─ sidebar.py        左侧栏：分类、应用来源
   ├─ clip_list.py      中间的记录列表、缩略图
   ├─ detail.py         右侧详情
   ├─ icons.py          图标（Segoe Fluent Icons 字体、程序图标）
   ├─ settings.py       设置窗口
   └─ theme.py          配色（跟随系统深浅色）
tools/uia_probe.py      探测某个软件的输入框能不能读
tests/                  单元测试
```

运行测试：

```bash
.venv\Scripts\python.exe -m unittest discover -s tests -t .
```
